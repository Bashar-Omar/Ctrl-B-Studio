# Project basis

CTRL-B Video Studio was designed around the workflow and architecture demonstrated by OpenRouterTeam's MIT-licensed `multimedia-explorer` example (Next.js, dynamic video model discovery, async video jobs and polling). The V1 source in this package is a purpose-built video-only implementation for CTRL-B's e-commerce / UGC workflow and uses OpenRouter's current documented `/api/v1/videos` API surface.
